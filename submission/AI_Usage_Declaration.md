# AI Usage Declaration

**Project:** DesignPatternsGroup52
**Members:** Nguyễn Đình Minh Huy (25125083), Trần Gia Huy (25125084)

We hereby declare that Artificial Intelligence tools (specifically, Google's DeepMind Antigravity AI coding assistant) were used to assist in the development of this project.

## Scope of AI Assistance

The AI assistant was utilized in the following capacities:

1. **Code Generation & Refactoring:**
   - Assisted in refactoring naive C++ implementations into robust, pattern-based designs (Observer, Interpreter, Mediator).
   - Recommended best practices for C++17 memory management (e.g., `std::shared_ptr`, `std::unique_ptr`) and modern idioms.

2. **LaTeX Documentation & Formatting:**
   - Generated TikZ code for UML Class Diagrams and conceptual models (e.g., Star Topology, Decentralized Mesh).
   - Resolved LaTeX compilation errors, such as `Overfull \hbox` and diagram overlapping issues.
   - Formatted execution traces and simulation logs into LaTeX tables.

3. **Logistics & Organization:**
   - Drafted summary documents (like `Changes.md` and this declaration).
   - Maintained a continuous execution log mapping AI prompts to Git commits.
